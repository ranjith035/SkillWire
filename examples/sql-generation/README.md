# SQL Generation Skill

An ASP 1.0 reference skill for converting natural language prompts into secure, dialect-aware SQL queries.

## Manifest Details

- **ID**: `io.github.example.sql-generation`
- **Version**: `1.0.0`
- **Supported Dialects**: PostgreSQL, MySQL, SQLite, Snowflake
- **Capabilities**: `text_generation`, `instruction_following`, `code_generation`

## Usage with Claude Code or Gemini CLI

```bash
asp install github:ai-skill-protocol/examples/sql-generation
asp generate claude
# or
asp generate gemini
```
